# WirePulse 4.3.0

- Compact 320 × 280 splash with a new welcome sound and a left-to-right, feathered fade-in of the WirePulse name, timed to the full audio duration.
- First launch and upgrades expand the same window into initial settings while the logo and name move to the upper-left corner. The macOS audio permission notice is now in initial settings and never blocks continuing.
- Native Liquid Glass on macOS 26 and later, with native blurred vibrancy on older supported macOS releases. Windows requests acrylic/blurred transparency. Linux Mint/Cinnamon uses a small, once-captured blurred desktop region where compositor blur is unavailable.
- Optional splash on every launch, available both in initial settings and Settings → Startup on macOS, Windows/WinUI and Linux. Subsequent splashes close after the sound without reopening initial settings or changing preferences.
- Existing welcome completion and preferences are preserved when toggling the splash option. All sound assets are bundled for offline playback.
