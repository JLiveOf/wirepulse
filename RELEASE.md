# WirePulse 4.5.0

- Reopen release highlights from Startup → What’s new? on every platform.
- Windows uses native WinUI acrylic windows for splash, initial settings, release highlights and update offers. Playback, startup registration and verified updates remain owned by the main process.
- macOS welcome and release highlights use a stronger glass tint and high-contrast body text for transparent system glass settings.
- Finishing initial settings or release highlights stops music and plays a short procedural vintage TV shutdown effect, without fading out. Moving from initial settings to highlights keeps the music running.
- Added a Spanish guide documenting Cider API token scopes and the current read-only integration; no Cider integration behaviour changed.
