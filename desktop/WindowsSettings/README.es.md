# Ajustes y editor nativos de Windows

[English](README.md) · [Compilar WirePulse](../README.es.md)

Este complemento WinUI 3 muestra los ajustes y controles del editor. El proceso principal de WirePulse mantiene el diseño, los ajustes, el dibujo y el audio. Se comunican mediante una tubería con nombre limitada al usuario.

Compila ambas aplicaciones con `../build-windows.ps1 -Test`. Conserva la carpeta publicada `WindowsSettings`, su ejecutable y su archivo `.pri` junto a WirePulse.
